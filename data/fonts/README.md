Shared fonts: every game can use these by family name or file name, in
engine font names (`con_font visitor1`) and Panorama CSS
(`font-family: "Visitor TT1 BRK"`). See docs/spec/bitmap-fonts.md.

The other shared fonts (visitor1.ttf, CWEBL.TTF, 04b09.ttf, Minusio.ttf,
anorexia.bdf) are private and not in git; see .gitignore.
